# GFC v1.1.6 发布说明

- **产品版本 / Tag：** `v1.1.6`
- **固件包名（权威）：** `gfc-client 1.1.0-r21`
- **状态：** current

## 摘要

OEM：强制关闭 `luci-light` / `luci-ssl*`（依赖已禁用的 `luci-app-firewall`），避免 `package/install` 因缺失 firewall 依赖失败。LuCI 仍为 `luci-base` + theme + `luci-mod-admin-full` + `luci-app-gfc`。

| control_plane_api | 0.1.0 |

## 构建机

```bash
cd /opt/gfc/sip-proxy && git pull && git checkout v1.1.6
bash gfc-client/deploy/immortalwrt/scripts/recover-package-install.sh

# manifest: gfc-client - 1.1.0-r21
```
