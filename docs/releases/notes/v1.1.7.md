# GFC v1.1.7 发布说明

- **产品版本 / Tag：** `v1.1.7`
- **固件包名（权威）：** `gfc-client 1.1.0-r22`
- **状态：** current（待 cut tag）

## 摘要

OEM GRUB 默认关闭串口控制台，避免 ImmortalWrt `console=ttyS0` 在最后导致 VMware VGA 在 `Run /sbin/init` 后无 login。转 VMDK **不能**解决此问题，必须重编镜像。

## 构建机

```bash
cd /opt/gfc/sip-proxy && git pull
bash gfc-client/deploy/immortalwrt/scripts/rebuild-gfc-image.sh
# 验收: grep CONFIG_GRUB_SERIAL /opt/gfc/immortalwrt/.config  → is not set
# manifest: gfc-client - 1.1.0-r22
```
