# GFC v1.1.5 发布说明

- **产品版本：** `v1.1.5`
- **固件包名：** `gfc-client 1.1.0-r20`

## 根因

`package/install` 时 **找不到** `kernel (= 6.6.143~57887482…-r1)`（目录里缺匹配的 `kernel_*.ipk`，或混入旧 vermagic `c2bd4df8` 包）。opkg 会对所有 kmod 误报 “incompatible architectures”。

## 构建机（推荐顺序）

```bash
cd /opt/gfc/sip-proxy && git pull
chmod +x gfc-client/deploy/immortalwrt/scripts/recover-package-install.sh
bash gfc-client/deploy/immortalwrt/scripts/recover-package-install.sh
bash gfc-client/deploy/immortalwrt/scripts/rebuild-gfc-image.sh
```

`rebuild` 现在会在 `package/install` 前自动做同样的 kernel 刷新（可用 `GFC_SKIP_KERNEL_REFRESH=1` 跳过）。
