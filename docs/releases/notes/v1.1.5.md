# GFC v1.1.5 发布说明

- **产品版本 / Tag：** `v1.1.5`
- **固件包名（权威）：** `gfc-client 1.1.0-r20`

OEM 固件构建与 BBR/opkg 源修复批次：kernel ABI 恢复不再误跑整树 `package/compile`；钉死 `libcap`+`libcap-bin`；去掉 CN unbound 误放的 `google.com`。
