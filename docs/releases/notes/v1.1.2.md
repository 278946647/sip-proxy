# GFC v1.1.2 发布说明

- **产品版本：** `v1.1.2`
- **固件包名（权威）：** `gfc-client 1.1.0-r17`（`PKG_VERSION=1.1.0` + `PKG_RELEASE=17`）

## 本版要点

1. **opkg 源**：OEM 镜像 `/etc/opkg/distfeeds.conf` 指向官方 ImmortalWrt 24.10.6（含匹配 vermagic 的 kmods），替换 `mirrors.vsean.net`（该镜像无 BBR kmod）。
2. **TCP BBR**：镜像预选 `kmod-tcp-bbr` + `kmod-sched`；`/etc/sysctl.d/12-gfc-bbr.conf` + 首启 `sysctl -p`。

不改动 nft / unbound / sing-box 数据面契约。
