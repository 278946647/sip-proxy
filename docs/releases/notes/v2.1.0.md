# GFC v2.1.0

- **Tag:** `v2.1.0`
- **Status:** current

## 摘要

策略路由泛域名收口版（后续开发透明模式）。域名组一层 `*.example.com`（不含顶点），LAN DNS 仍走现有 hijack → unbound `:53`；`gfc-api` 嗅探 UDP/53 应答，把一层子域 A 记录写入 `usr_dom_*`。未改 nft / unbound / sing-box 生成器契约。

## 升级

- **2.0.x → 2.1.0：** 同 Major 直升；Runtime OTA 可下发 agent/LuCI。
- **1.x → 2.1.0：** 禁止直跳；先 `v1.1.9`，再固件/人工（见 `docs/releases/notes/v2.0.0.md`）。
- 新 OEM 镜像 rebuild 后 manifest 须为 `gfc-client 2.1.0-r1`。
