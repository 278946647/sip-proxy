# GFC v1.1.8 发布说明

- **产品版本 / Tag：** `v1.1.8`
- **固件包名（权威）：** `gfc-client 1.1.0-r23`

## 摘要

真机/VMware 停在 `Run /sbin/init`：ImmortalWrt 24.10 强制 `console=ttyS0` 在 cmdline **最后**，login 进串口。r22 的 `CONFIG_GRUB_SERIAL` 在 24.10 **已不存在**，关它无效。r23 直接改 x86 `image/Makefile`，在 serial 后再追加 `console=tty1`。

## 构建

```bash
cd /opt/gfc/sip-proxy && git fetch --tags && git checkout v1.1.8
export IMT_SRC=/opt/gfc/immortalwrt
bash gfc-client/deploy/immortalwrt/scripts/rebuild-gfc-image.sh
grep GFC_VGA_CONSOLE_LAST "$IMT_SRC/target/linux/x86/image/Makefile"
grep gfc-client "$IMT_SRC"/bin/targets/x86/64/*.manifest   # 1.1.0-r23
zcat "$IMT_SRC"/bin/targets/x86/64/*combined*efi*.img.gz | strings | grep -E 'console=tty'
```
