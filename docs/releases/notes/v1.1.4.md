# GFC v1.1.4 发布说明

- **产品版本：** `v1.1.4`
- **固件包名（权威）：** `gfc-client 1.1.0-r19`

## 本版要点

修复 ImmortalWrt `package/install` 连锁失败：stock `luci`→`firewall4`→`kmod-nft-fullcone` 与 GFC 关闭 fullcone 冲突；并处理 `kmod-r8168` / 缺失 `kernel` ipk。

LuCI 改为 `luci-base` + theme + `luci-mod-admin-full` + `luci-app-gfc`。fw4 仍由首启脚本禁用（即使未装 firewall4 也无妨）。

## 构建机

```bash
cd /opt/gfc/sip-proxy && git pull
rm -rf /opt/gfc/immortalwrt/build_dir/target-x86_64_musl/root-*
bash gfc-client/deploy/immortalwrt/scripts/rebuild-gfc-image.sh
```

若仍报 `kernel (= 6.6.143~…)` 无法满足：

```bash
cd /opt/gfc/immortalwrt
rm -rf bin/targets/x86/64/packages
make package/kernel/linux/compile -j$(nproc) V=s
make package/compile -j$(nproc) V=s
```
