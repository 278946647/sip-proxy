# GFC v2.0.0

- **Tag:** `v2.0.0`
- **Status:** current
- **Released:** 2026-08-25
- **级别:** Major / Dataplane-Arch

## 摘要

旁路模式（`proxy_mode=bypass`，NFT §9.3 Option B）**首个可运行产品发版**。默认仍为网关模式；旁路仅设备 Web 切换。`gfc-client` 钉扎 **`2.0.0-r1`**。

实现前 1.x 快照仍为 **`v1.1.9`**（规范已批、生成器未改时的回滚点）。

## 跨 Major（1.x → 2.0.0）

**禁止 Runtime OTA 直跳。**

1. 1.x 舰队先升到桥接 **`v1.1.9`**（同 Major 1 内直升）。
2. 再以 **固件刷写 / `install-runtime` / OEM 镜像** 进入 `v2.0.0`（`gfc-client 2.0.0-r1`）。
3. 上线后默认 `gateway`；旁路在管理 LAN 按 `docs/BYPASS_MODE.md` 开局。

控制面 API 仍为 `0.1.0`；payload `proxyMode` 客户端忽略（平台 API 拒绝写入为后续任务）。
