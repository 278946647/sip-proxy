# GFC v1.1.3 发布说明

- **产品版本：** `v1.1.3`
- **固件包名（权威）：** `gfc-client 1.1.0-r18`

## 本版要点

1. 修复 `package/install`：`gfc-client` 与 `base-files` 争抢 `/etc/opkg/distfeeds.conf`。
2. 关闭 `default-settings` / `kmod-nft-fullcone`，避免自编译内核 vermagic 不匹配导致装包失败。
3. 官方 opkg 源仍由 **镜像 files overlay** 覆盖；BBR 仍 bake 进镜像。
